## Build and deploy

`pnpm build` bundles the Hono Node API and all shared workspace source through esbuild, then builds/prerenders the public web. `api/index.ts` references the generated server artifact. Raw workspace `.ts` package exports must not be assumed to survive Vercel function tracing; the first deployed API failed this check and prompted explicit bundling.

Use `pnpm dlx vercel@latest deploy --prod --yes` after tests and owner approval; preview deployments use `deploy --yes`. No seed or migration runs implicitly at frontend build. Preserve local `.vercel` link and use the correct project; do not modify unrelated Neon workloads.

## Update semantics

Foreground authorized reads refresh at five-second intervals across the query clients. Dashboard shows refresh time/errors; failed refresh is stale, not confirmed current. This provides near-live database-backed updates, **not guaranteed subsecond push**, offline freshness or background mobile delivery. Neon Realtime beta was not enabled; Ably credentials and complete affected-party fan-out remain unconfigured. Polling may keep the database awake and consumes plan usage; monitor actual costs/limits before operating at scale.

# Metric definitions

Current dashboard is **bounded to the 1,000 newest records per permitted resource**, explicitly disclosed in the API and UI. It is not a full accounting/impact export. Scope is the verified selected membership: platform only for privileged PLATFORM memberships; customer, collector, partner and facility scopes remain restricted.

| Display | Unit / date basis | Definition and limitations |
|---|---|---|
| Active service sites | sites / current status | `sites.status=ACTIVE`; **not** a claim of active paying sites |
| Upcoming & in-progress | jobs / occurrence records, all dates | SCHEDULED, ASSIGNED, EN_ROUTE, ARRIVED; no fabricated calendar forecast |
| Completed | jobs / occurrence records | COLLECTED or documented PARTIALLY_COLLECTED; not receiving or treatment |
| Missed | jobs / occurrence records | MISSED or FAILED; no reliability denominator is implied |
| Collected organics | kg / collector occurrence | Sum collection net grams / 1,000; includes explicitly identified estimates; not delivery/composting |
| Accepted at facility | kg / receiving records | Independent receiving accepted mass; submitted/reviewed evidence status retained; no treatment/output assertion |
| Rejected at facility | kg / receiving records | Independent rejected mass; residual destination completion separately recorded |
| Awaiting reconciliation | manifests / current state | Not RECONCILED or CLOSED; includes undelivered/in-progress manifests |
| Open service issues | complaints / current status | Not RESOLVED |
| Invoiced | currency minor units / issued snapshots | Sum issued totals in each ledger separately; not earned revenue |
| Outstanding | currency minor units / current allocations | Sum invoice total minus confirmed allocated payment amounts; pending references excluded |
| Confirmed payments | payment records / review status | Count CONFIRMED; not a mixed-currency cash amount |

Record list From/To filters use **record creation date**, not occurrence/service date, clearly labelled. Pilot display timezone is Africa/Monrovia; timestamps stored UTC. Generation time, scope and paging are returned by API. CSV exports only the authorized bounded page and neutralizes spreadsheet formula prefixes.

Not yet released: active paying sites by service period; receiving coverage by source pickup mass; rejection-rate denominator; confirmed treatment evidence; route earned/invoiced/cash separation; quality-reviewed output; full-ledger financial aggregation and configurable scope/date/service-area filters. Implement and test their definitions before displaying them.

For future reports, receiving coverage must disclose allocated pickup mass with independent receiving / eligible collected mass, same occurrence cohort, not simply count jobs. Rejection rate uses rejected measured receiving mass / measured receiving mass, not all pickup mass. Stage measurements must never be summed as a single recovery total. Treatment allocations and compost output need independent evidence, not weighted pickup proxies.

Emissions estimation and compost sales remain disabled. No avoided-emissions factor, certification, carbon credit or carbon-claim ownership is generated by a pickup, payment or app state.
